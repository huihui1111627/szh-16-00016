# 连续化工反应异常工况处置推演

这是一个零依赖的网页原型，用离散时间仿真连续化工反应装置。操作人员调整阀门、负荷或冷却回路后，结果不会瞬时跳到反应器或成品段，而是按照进料、预热、混合、反应、分离精制和成品监测的顺序逐段传播。

## 运行

直接用浏览器打开 `index.html`，或在当前目录启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

运行回归测试：

```bash
npm test
```

测试只依赖 Node.js 内置测试运行器，不需要安装第三方包。

## 仿真阶段

- 正常：温度、压力和成品纯度处于正常窗口。
- 预警：任一参数越过预警线，但仍允许人工纠偏。
- 保护介入：自动投入紧急冷却、降负荷、泄压或把产物切到不合格罐。
- 紧急停车：保护无法阻止关键参数越限时，切断进料并保持紧急冷却与泄压。
- 恢复生产：先降压降温，再按最后有效配置低负荷爬坡，合格后回到正常生产。

## 处置方案

在任一稳定点可以点击“稳定点生成新方案”。当前方案失败后，点击“放弃当前尝试”会回到该方案的稳定起点，并把尝试保留为失败记录。

最后有效配置只在正常阶段持续稳定 10 秒后更新。预警、保护、紧急停车或失败回滚都不会覆盖它；恢复生产默认调用该配置并将负荷限制在 80%。

## 传播时序

- A/B 进料管线：2 秒。
- 预热器：3 秒。
- 反应器出口到分离入口：3 秒。
- 分离精制到成品质量监测：5 秒。
- 阀门开度和负荷按执行机构速率渐进变化，冷却切换从反应器热平衡开始体现，质量异常最后出现在成品段。

## 文件结构

- `index.html`：推演台页面结构。
- `styles.css`：工业控制台样式。
- `js/engine.js`：纯 JavaScript 仿真内核，可同时在浏览器和 Node.js 中运行。
- `js/app.js`：界面状态绑定和交互。
- `tests/engine.test.js`：传播、联锁、恢复、方案分支和回滚回归测试。
