# 连续化工反应装置异常工况处置推演系统

用于操作人员演练异常工况处置：进料比例、温度、压力、冷却能力、产品纯度沿物料流程
**连续且有传播延迟**地变化；错误操作组合可导致温度失控、压力累积或下游质量异常。

## 工艺流程模型

A/B 进料 → 混合管线(10s 传播延迟) → 连续搅拌反应器(CSTR) → 产品管线(20s 延迟) → 产品罐

- 进料阀开度、生产负荷经执行器斜坡（非瞬时）改变实际进料。
- 反应器：阿伦尼乌斯动力学 + CSTR 物料/能量衡算（Q = F·Cp·ΔTad·x）。
- 冷却：主/备用回路，回路切换 30s 过渡期内冷却能力呈下凹衰减。
- 压力：温度饱和蒸气压 + 流动背压，超 3.5MPa 安全阀起跳。
- 产品纯度：转化率、温度选择性、配比选择性综合决定，经产品管线延迟后才显现。
- 额定稳态标定：约 90.7°C / 1.28 MPa / 纯度 97%。

## 阶段状态机

NORMAL（正常）→ WARNING（预警：T≥100°C / P≥2.0MPa / 纯度<92%）
→ PROTECTION（保护介入：T≥108°C / P≥2.3MPa，冷却强制全开、负荷限 70%）
→ TRIP（紧急停车：T≥120°C 或 P≥3.5MPa，切进料、急冷泵满负荷、阀位与管道复位）
→ RECOVERY（恢复生产引导：降温置换 → 20% 低负荷引料确认 → 自动升负荷至 60%）
恢复中再次越线则回退停车（ABORTED）。

## 已验证的关键工况

- 关小 B 阀（限量组分不足）：仅造成下游纯度异常，不飞温。
- 过量开 A 阀：放热增加，可进入预警。
- 过量 A + 错误时机切换冷却（过渡期能力塌陷）：预警→保护→温度失控停车。
- 保护介入后立即降负荷并恢复配比：可避免停车并回到正常。
- 停车后走恢复引导：约 211s 在 60% 负荷下稳定恢复，纯度 97%。
